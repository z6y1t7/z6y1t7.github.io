# 黄时雨的个人名片网页

## 项目介绍

这是我在 Vibe Coding 课程里完成的第一个作品，一个只有一个 HTML 文件的个人名片网页。

做它的时候我给自己定的方向是"安静、克制、像一本黑白画册"：白底、衬线字体、手绘线条的山茶花，黑白色块之间做出撕纸一样的边缘。页面一共三屏——第一屏是封面问候，第二屏介绍我自己，第三屏是我的三个兴趣。右上角可以切换夜间模式。

## 如何运行

不需要安装任何东西。把仓库下载到本地后，双击 index.html 就能在浏览器里打开。所有样式、脚本和山茶花图案都写在这一个文件里，没有外部图片和字体，所以完全离线也能正常显示。

这个仓库开通了 GitHub Pages，也可以直接在线访问。

## 已完成功能

- 三页式卡片结构：封面（你好，我叫黄时雨）、个人信息（昵称章鱼、中国人民大学、ENFJ 主人公、一句话介绍）、兴趣爱好（看书、滑冰、睡觉）
- 四种翻页方式：页面两角的 NEXT 与 BACK 按钮、键盘方向键和空格键、手机上左右滑动、底部指示条直接跳页
- 日间与夜间模式切换：点击右上角按钮，整套配色通过 CSS 变量整体切换，按钮文字也随之变化
- 山茶花装饰：用纯 SVG 线条绘制了完整花朵、花苞、花枝、带叶花朵、单瓣飘落花瓣五种形态，以水印和散落花瓣的方式分布在各页
- 撕纸边缘效果：黑白色块交界处用 SVG clip-path 做出不规则的撕裂毛边
- 入场动画：每次切页时元素按顺序交错淡入上浮
- 手机端适配：480px 以下自动缩小字号与间距、隐藏部分装饰，不会出现横向滚动

## 我的探索

最有意思的探索是通过给 AI 发送指令一步步改造页面的过程。我先让它做出书页翻动的效果，后来又改成现在更柔和的淡入过渡；山茶花也是这样，从最开始的一两朵水印，通过不断描述我想要的黑白手绘风格，最后让它画出了花朵、花苞、花枝、单瓣飘落的花瓣这一整套 SVG 图形。我发现把想法讲得越具体，得到的效果就越接近心里的样子，这种"描述需求、看效果、再调整"的循环本身就是一个学习过程。

## 遇到的问题

开发中排查过最麻烦的是窄屏横向滚动问题。把浏览器窗口缩窄到手机宽度时，页面内容会超出屏幕出现横向滚动条。通过在开发者工具里切换不同设备尺寸，一点点定位到是哪些元素的宽度和间距没有跟随屏幕收缩，最后在 html 和 body 上限制了横向溢出、给卡片容器加了最小宽度约束、给大标题加了换行保护，并单独写了一段手机宽度下的样式，才彻底解决。
